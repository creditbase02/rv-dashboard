啟動這台電腦的 Bloomberg 連線

已安裝 Bloomberg 的電腦，可下載啟動包完成連線，不必下載整個專案。

下載 Windows 啟動包 ↓
  1. 首次設定

    完整解壓縮 ZIP，雙擊 Setup.cmd。需要 Windows 與 Python 3.12 64-bit；設定只需做一次。

  2. 登入後啟動

    登入 Bloomberg Terminal，雙擊 Start.cmd。它會自動開啟已連線的網頁；保持命令視窗開啟。

  3. 手動取得快照

    看到「本機服務就緒」後，按上方取數按鈕。每按一次只查一次，不會刷新 Excel。

尚未安裝 Python、公司網路限制，或連線失敗？

啟動包內含中文 README。Python 官方下載 ↗；公司電腦可請 IT 安裝 Python 3.12 64-bit。首次設定會從 Bloomberg 官方來源與 PyPI 安裝必要套件；Bloomberg 帳號仍需具備 BQL 及所需行情權限。

瀏覽器若詢問本機網路存取權限，請允許此站。憑證失效時重新執行 Start.cmd，使用它開啟的新頁面。若顯示 8768 已被占用，先在舊啟動器視窗按 Ctrl+C，再啟動一次。

瀏覽器不能直接替你啟動電腦程式；下載後須解壓縮並雙擊啟動。結束使用時在命令視窗按 Ctrl+C，服務即停止。
